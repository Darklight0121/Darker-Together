# Darker Together

A co-op mod for **Darkest Dungeon** (the first game, Windows, Steam): two players, each with their
own campaign, meet for an expedition with two heroes each.

This is an early test. Expect rough edges.

## Download

Get `DD_Coop_Test.zip` from the latest [release](../../releases/latest), unzip it anywhere and open
**`Darkest Dungeon Co-op.bat`**. The window installs the mod, connects you to your friend over
Steam, and updates itself from this repository.

Read `READ ME FIRST.txt` in the zip before playing.

## Requirements

- Both players: the same Darkest Dungeon version (no beta branch), the same DLC, no other mods.
- The mod only talks to your friend, directly over Steam's friend-to-friend connection.
